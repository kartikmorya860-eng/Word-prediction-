# Word Prediction LSTM Model

This notebook demonstrates a simple word prediction model using an LSTM (Long Short-Term Memory) neural network.

## What this project does

- Uses a small FAQ-style text corpus as training data
- Tokenizes the text with Keras Tokenizer
- Converts text into input sequences for next-word prediction
- Trains an LSTM-based model to predict the next word
- Generates text iteratively from a seed prompt

## Files

- word_pridiction_LSTM_model.ipynb - Main notebook containing the full workflow

## How to run

1. Open the notebook in Jupyter Notebook or JupyterLab.
2. Run all cells from top to bottom.
3. Change the input text in the prediction section to try different prompts.

## Notes

This is a beginner-friendly example of text generation using deep learning. The dataset used here is small, so the model is meant for learning and demonstration rather than production-level performance.
